# inbox/

Staging area for raw material — emails, PDFs, transcripts, screenshots,
exports — waiting to be distilled into the wiki.

Drop files here, then ask a session to **process the inbox**. It will read
everything, propose a single plan covering all items, and execute after you
confirm: facts distilled into `NOTES.md` and `TASKS.md`, material worth keeping
moved to `sources/` with a provenance note, ephemeral originals deleted.

Contents are gitignored. Only this README is tracked.
